# Security Policy

This document describes the security policy for GRUB2 Theme Nuci, a static GRUB2 theme package consisting of a theme definition file and icon assets. The theme contains no executable code, runtime logic, dependencies, or network connectivity.

## 🚨 Reporting a Vulnerability

Please do not disclose suspected vulnerabilities publicly before maintainers have had an opportunity to validate and remediate them.

To report a vulnerability:
- [GitHub Security Advisories](https://github.com/hmlendea/grub2-theme-nuci/security/advisories)
- Contact the maintainers directly

## 📌 Scope

The original maintainers are not responsible for changes, modifications, or security issues introduced by downstream forks.

The subsequent report categories are in scope for this repository:
- Malicious content embedded in theme assets (e.g., crafted image files)
- Supply-chain compromise of distributed theme packages

The subsequent categories are out of scope unless explicitly stated to the contrary:
- GRUB2 bootloader vulnerabilities (upstream responsibility)
- Operating system or firmware vulnerabilities
- Issues in downstream forks or modified distributions

## 📢 Disclosure Policy

This project follows coordinated disclosure:
1. Vulnerabilities are investigated privately.
2. A remediation plan is prepared and validated.
3. Public disclosure is published after a fix, mitigation, or agreed risk decision is available.
4. Credit is attributed in accordance with reporter preference and project policy.
